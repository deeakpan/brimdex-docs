### Official Brand Colors

**Primary Brand Color (Brimdex Text / Main Identity)**  
- Cyan: `#66b2c6`

**Outcome Colors**
- **Break** (Red variation): `#ab1d1d`
- **Bound** (Green variation): `#38e23c`

**Gradient (for backgrounds, accents, or hero sections)**  
- From: `#3533cd`  
- To: `#000000` (solid black)

### Typography

**Display / Branding Text (Headings & Logo text)**  
- Primary: **League Spartan** (Bold weights recommended)  
- Alternative: **Shrikhand** (for more bold/unique personality)

**Body / Descriptions / Tags**  
- **Arimo** (Regular & Bold)

### Usage Guidelines

- Use **#66b2c6** as the main brand color for "Brimdex" text, logos, and accents.
- Use **#ab1d1d** exclusively for **Break** elements (red side).
- Use **#38e23c** exclusively for **Bound** elements (green side).
- The cyan `#66b2c6` should dominate the overall brand identity.
- Gradient (`#3533cd` → `#000000`) works well for dark backgrounds, cards, or promotional visuals.
- Always pair League Spartan / Shrikhand for titles and Arimo for readable text.
- Maintain good contrast — especially when using red/green on dark backgrounds.

### What's Inside This Pack

- **Logos/** → All logo variations (full color, black, white, icon-only, horizontal, stacked, with/without Beta)
- **Colors/** → Palette reference images + this guide
- **Fonts/** → League Spartan, Shrikhand, Arimo (where legally included)

### Do's and Don'ts

**Do:**
- Keep the cyan `#66b2c6` prominent for Brimdex branding
- Clearly separate Break (red) and Bound (green) in market visuals

**Don't:**
- Change the official colors for Break/Bound
- Use other fonts for main branding text
- Stretch or distort the logo
